This Note App is made using HTML, CSS, and JavaScript. The HTML file is the structure of our app. It contains a <div> tag with the
 class “container” that holds everything. Inside it, I used <h1> for the title, <textarea> for writing a note, and a <button> to
 add the note. I also used another <div> with the id “notesContainer” to show all the saved notes on the page. The <script> tag at
 the end connects our JavaScript file, and the <link> tag in the <head> connects the CSS file.


In the CSS file, I designed the app to look neat and simple. The body uses display: flex to center the main box on the screen. 
The .container class gives a white background, rounded corners, and a small shadow to make it look nice. The textarea is styled
 to be easy to write in, and the button changes color when we hover over it. Each note is styled using the .note class with a blue
 border and a small red delete button on the top right.

In the JavaScript file, I wrote all the logic that makes the app work. When we click the Add Note button, the script takes the text

 from the textarea and saves it in the browser’s localStorage, so notes don’t disappear when the page refreshes. The function
 showNotes() displays all saved notes, and the deleteNote() function removes a note when the delete button is clicked.
 I also used JSON.parse() and JSON.stringify() to convert data to and from text format for saving in localStorage.
